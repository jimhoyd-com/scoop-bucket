# GitRoll Scoop bucket

Install [GitRoll](https://github.com/jimhoyd-com/gitroll) on Windows:

```powershell
scoop bucket add gitroll https://github.com/jimhoyd-com/scoop-bucket
scoop install gitroll/gitroll
```

Upgrade with `scoop update gitroll`, and remove it with `scoop uninstall gitroll`. Your Rolls are never deleted.

Manifests here are generated and published automatically by the [GitRoll release workflow](https://github.com/jimhoyd-com/gitroll/blob/main/.github/workflows/release.yml), after the package is installed with Scoop and tested on Windows. Please don't edit them by hand; open issues and pull requests on [jimhoyd-com/gitroll](https://github.com/jimhoyd-com/gitroll).
